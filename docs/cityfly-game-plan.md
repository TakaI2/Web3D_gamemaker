## 1. ゴール

現在の「サンドボックス（敵が湧き続け、死んでも復活）」を**トレーニングモード**として残しつつ、
タイトル → OPシナリオ → 本編（パラメータ・イベント駆動）→ 分岐ED → タイトル、という
**1周のゲームループ**を追加する。分岐・進行は flow-editor のグラフで編集可能にする。

```
タイトル画面 ─ ゲームスタート ─→ OPシナリオ ─→ ゲーム本編 ─┬─ ウォーカー撃破(通常ルート) ──────────→ Good ED ─→ タイトル
     │                                                        ├─ Badルート移行 → スパイダーキャリア撃破 → Bad ED ──→ タイトル
     │                                                        └─ プレイヤー死亡（両ルート共通）─→ ゲームオーバー ─→ タイトル
     └─ トレーニングモード（現行ゲームそのまま・ループ外）
```

### 敵名の対応（決定）
| 脚本上の名前 | 実装 | 役割 |
|---|---|---|
| ウォーカータンク | ウォーカー（4脚・実装済み） | 通常(Good)ルートのボス。撃破＝終戦→Good ED |
| スパイダーキャリア | スパイダータンク（6脚大型・実装済み） | **Badルート専用**。撃破＝終戦→Bad ED。ゲーム内表記は「スパイダーキャリア」に統一 |

## 3. アーキテクチャ

### 3.1 ゲーム状態機械（city-fly 内に追加）
`gameMode: 'title' | 'training' | 'op' | 'play' | 'ed'`
- **title**: DOMオーバーレイ（スタート／トレーニング）。背面では都市生成を通常どおり進める（元案の「裏で生成」は現行の起動時生成で実質満たせる。生成完了までスタートボタンは「準備中…」表示）
- **op/ed**: 2Dシナリオプレイヤを全画面表示。ゲーム進行は停止（敵AI・被弾なし）
- **play**: 本編。パラメータ・イベント駆動。敵は**イベントの投入指示でのみ**出現（自動湧き停止）
- **training**: 現行挙動そのまま（無限湧き・死亡→リセット復活）

### 3.2 パラメータ（GameParams）
| 名称 | 定義 | 備考 |
|---|---|---|
| 都市被害率 cityDamage | 崩壊完了した建物数 ÷ 総建物数 ×100 | `startCollapse` でカウント。誰が壊しても加算 |
| 手配度 wanted | 既存 + **プレイヤー起因の建物破壊**で加算 | 破壊APIに source（player/enemy）引数を通す |
| 敵損耗率 attrition | 重み付き撃破ポイント ÷ シナリオ想定総量 ×100 | 仮: ジェット=3, ウォーカー=20, スパイダーキャリア=35（→§8） |
| プレイヤーHP | 既存 | しきい値イベントに使用 |

### 3.3 イベントシステム（宣言的JSON＋ランタイム）
`public/cityfly/events.json`（新設）に定義し、ランタイムが毎フレーム条件を評価して1回発火。

```json
{ "id": "attr50", "when": { "param": "attrition", "op": ">=", "value": 50 },
  "do": [ { "type": "talk", "talk": "t_walker_in" }, { "type": "spawn", "enemy": "walker" } ] }
```
- **when**: param しきい値（クロス検知・1回のみ）／kill（特定敵撃破）／action（捕食した等）／gameStart／playerDead
- **do**: `talk`（ゲーム内会話）／`scenario`（2Dシナリオ再生）／`spawn`（敵投入）／`flag`（ルートフラグ）／`flow`（フローのポート発火＝分岐・終了）
- 元案の具体イベントを初期データとして収録:
  - HP≤50%: nei会話（マントが！…） / HP≤25%: nei会話（飛ぶのがキツい…）
  - cityDamage≥40: 市長/博士/ネイ会話
  - attrition≥50: 幹部シナリオ＋**ウォーカー投入**（両ルート共通）
  - wanted≥しきい値: **Badルート移行**（暴走シナリオ差し込み。以降ウォーカー撃破では終戦しない）
  - attrition≥75 かつ Badルート: エリクシラシナリオ＋**スパイダーキャリア投入**
  - kill:walker（通常ルート）: 終戦→**Good ED** / kill:spider（Badルート）: 終戦→**Bad ED**
  - playerDead: **ゲームオーバー**（両ルート共通）→タイトル

### 3.4 2Dシナリオ（紙芝居）プレイヤ
- .story.json を拡張し **2D用op** を追加（3D opと共存）:
  `bg.show(image)` / `portrait.show(actor, expr, side)` / `line(actor, expr, text)` / `bgm` / `se` / `choice`(将来)
- 表示: 背景1枚＋下部メッセージウィンドウ＋**左側に顔グラ**（正方形1000×1000、キャラ×表情で複数）
- 素材フォルダ（新設）: `public/scenario2d/bg/…`, `public/scenario2d/face/<キャラ>/<表情>.png`
- story-editor に2D opの編集UIを追加（アクター欄は流用、プレビューは2Dモード）
- RPG-Game リポの機能相当は「背景・立ち絵/顔グラ・テキスト送り・BGM/SE・分岐」を対象範囲とする（§7 要確認）

### 3.5 ゲーム内会話（play中）
- 画面下部に**シナリオと同一デザインのメッセージウィンドウのみ**表示（背景なし・ゲームは進行continue）
- 顔グラ＋話者名＋テキスト。クリックまたは4秒で次行、行列キューで連続再生
- 会話データ: `public/cityfly/talks.json`（id→行配列。イベントの `talk` から参照）
- ルート中のランダム雑談にも同システムを使用（周期＋確率）

### 3.6 flow 統合
- `public/flow/cityfly.flow.json`: start → story(op) → battle(本編) → 分岐 → story(good/bad ed) → end
- battleノードの出力ポートを3系統に拡張: `good`（ウォーカー撃破・通常ルート）/ `bad`（Badルートでスパイダーキャリア撃破）/ `lose`（プレイヤー死亡=ゲームオーバー）
- flow-runner は素JSなので city-fly に直接組込み（iframe不要）。ルート追加は flow-editor で編集
