# チュートリアルステージ 要件・計画（tutorial_plan.txt 準拠）

## 方針（アーキテクチャ）

**city-fly に `?map=tutorial` として統合**する。別ページは作らない。
理由: 必要システム（飛行操作・ビーム/チャージ・グラブ/投擲/盾・吸血・ダメージ損耗・戦闘機・
会話/シナリオ/HUD/撃墜スコア）がすべて city-fly.js に実装済み。新規はステージ構築とボスのみ。

- `MAP_NAME === 'tutorial'` で分岐。街モード（floz/mytown）には一切影響を与えない
- 新規モジュール `city-fly/tutorial.js`（ステージ構築・進行管理・ボス）を city-fly.js から import
- flow / events / talks / story の fetch パスをマップ名でパラメータ化
  （tutorial 時: `flow/tutorial.flow.json`, `cityfly/tutorial_events.json`,
  `cityfly/tutorial_talks.json`, `story/tutorial_op.story.json` / `tutorial_ed.story.json`）
- 地形: 平坦・小サイズの `public/maps/tutorial.map.json` をスクリプト生成
  （既存 buildMapGround / groundYAt がそのまま動く。道路・建物・水なし）

## ステージ構造

- 全6部屋＋廊下を一直線（X軸方向）に連結。全体 約2000×600m・高さ≤300m
  （floz=6400×6400×高低差 の容積1/3を大きく下回る）
- 壁・床・天井 = `addCollBox`（既存の押し出し collision がそのまま効く。
  敵弾の遮蔽・rayCityBox 命中も自動で効く）
- マテリアル: three.js games_fps 例と同様 = ライトグレー基調のフラット面＋
  チェッカー/グリッドのプロシージャルテクスチャ、ヘミスフィアライト
- **隔壁**: クリア条件達成で開く（スライド開閉アニメ＋SE）。次室に入ると背後で閉鎖（戻り不可）
- 破壊可能な構造物（部屋2の建物・部屋2出口の高HP隔壁・部屋4要塞など）は
  既存の建物パイプライン（md + InstancedMesh + addCollBox + damageBuildingRec/carve/collapse）に登録
  → 被弾カーブ欠損・ディソルブ崩壊・赤フラッシュが街と同一挙動

## 各部屋

### 部屋1 移動訓練
- 入り組んだ立体通路（水平・垂直・斜めの移動を強制するレイアウト）
- クリア: 最深部ゴール（発光リング）到達
- 開始/中間会話（博士・ネイ）、操作ヒント表示（PC/スマホ自動判別のDOMオーバレイ）

### 部屋2 攻撃訓練
- 一発破壊ターゲット（人型シルエット/カプセル、hp=1の「建物」として登録→被弾/破壊FX共通、
  破壊で addKill('target')=撃墜数加算）。建物型構造物の中に隠しターゲットあり
- クリア: 全ターゲット破壊 → 出口の**高HP隔壁**（スパイダー級HP）をチャージショットで破壊
- ゲージ（チャージ）説明の会話＋ヒント表示

### 部屋3 空中戦訓練
- 訓練用戦闘機: 既存 jets を**個体パラメータ化**（spMin/spMax減・爆撃なし・弾速/威力減・
  撃墜されるたび補充）
- 下層に破壊可能な建物オブジェクト＋ダミードール多数（地面や建物の上を走り回る）
- **セーフティエリア**: 光の柱＋発光リングで明示。ダミードールを掴んで運び入れると「救出」
- クリア: 戦闘機20機撃墜 かつ 救出5体

### 部屋4 グラブ攻防訓練
- 車サイズ〜ビル/船サイズのグラブ可能オブジェクト多数（発光マーカー付き）。
  大型は街の船と同じ挙動（円筒転がり・投擲ダメージ・被弾でディソルブ）
- 中央に**要塞**＋複数砲台（`fireEnemyBolt`＝スパイダーキャノンと同弾速）
- 要塞HPは激高 → 巨大物の投擲（質量×速度ダメージ既存式）で破壊するのが正解
- クリア: 要塞破壊

### 廊下 捕食訓練
- **プネウマドール**3体（水色発光マネキン・立位）。掴むとラグドール化、
  既存の捕食システムで吸血可（回復量 ken の 1/3）。吸い尽くし/破壊でディソルブ消滅
- 回復で服・マントが修復される（既存: HP連動で自動修復済み）ことを会話で説明

### 部屋6 ボス戦
- 正二十面体コア＋周回する正八面体子機（8機想定）。ステージ色違いマテリアル・被弾赤フラッシュ
- 移動: TPS-Flight NPC式ランダム飛行（float/drift/dash）→ 攻撃パターン→戻る、の繰り返し
  1) 移動しつつ子機ビーム（スパイダーキャノン同等） 2) 子機射出（当たり判定あり）
  3) 前兆→本体から高速極大ビーム連射 4) 訓練戦闘機10機射出
- 子機: 被弾でノックバック＋壁反射（TPS-Flight bounceAxis式）→しばらくして帰還。
  数発で破壊（ディソルブ）。**グラブ可**（carsAndJets プロキシ登録→盾/投擲が既存系で自動対応）、
  本体にぶつけてダメージ。全滅後しばらくしてディソルブ復活
- 撃破: ゆっくり降下→接地でディソルブ消滅 → クリア会話 → EDシナリオ
- ステージ内にグラブ可能な巨大オブジェクト多数

## シナリオ・会話・その他

- OP/ED: tutorial_plan.txt のセリフで story JSON 新規作成（BGM=crisis_2、ゲーム中=Sound_Wave）
- 部屋ごとの開始/中間/クリア会話: talks.json＋events（既存 queueTalk/字幕UI）。
  進行条件は tutorial.js が監視し ev.flags / flow port で駆動
- 被弾ランダム会話（きゃっ/いたっ）＋HP50%初回のマント警告会話（5連）
- 新アイテム **ダミードール**: ken システム流用。VRMスケルトンに基本図形カプセルを
  ボーン装着したマネキン表示（元メッシュ非表示）。歩行/逃走AI・グラブ・速話は ken と同一、
  吸血のみ不可フラグ。破壊は車と同じパターン（破片＋消滅）
- 撃墜スコア: ターゲット/戦闘機/子機/ボスすべて addKill 加算（既存UI）
- 常時60fps維持（各フェーズで計測）。街モードへの回帰バグなし（floz で既存検証を再実行）
