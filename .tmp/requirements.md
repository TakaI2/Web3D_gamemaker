# 要件定義: 海からの侵攻（スパイダーキャリア母艦化）

対象: EP2 アルデン（`arden` マップ）／実装はマップ非依存（海の位置は `.map.json` の `water[].level === 0` から自動算出）

## 背景（現状）

| 要素 | 現状の挙動 | 該当コード |
| --- | --- | --- |
| 敵戦闘機 | プレイヤー周囲 380〜500m の**全方位ランダム角**に湧く | `jetAirPos()` / `spawnJets()` |
| ウォーカータンク | 市街境界内でプレイヤーから 250m の**ランダム角**に湧く | `spawnWalker()` |
| スパイダーキャリア | 市街境界内 450m のランダム角に湧き、**街を徘徊**して破壊 | `spawnSpider()` / `updateSpider()` |
| 出現制御 | `events.json` の `spawn` アクションが `ev.spawnAllow[kind]` を立てる | `runEvAction()` / `enemyAllowed()` |
| 分岐 | `badRoute` フラグ＋損耗75%で spider 投入 → spider 撃破で **bad ED** | `ep1_events.json` |

マップ側の海（`arden`）: `level === 0` の矩形が z=1410〜3050、x=-3200〜3200（＝南側一帯）。海底標高は最深 -47m。

## 機能要件

### R1. 敵戦闘機は海から飛来する
- R1-1. 初回出現・撃墜後の再出撃とも、出現位置を**海側**に限定する（現状の全方位ランダムを廃止）。
- R1-2. 母艦が健在なら**母艦の甲板付近から発進**する。母艦が居ない／破壊済みなら海の方角から飛来する。
- R1-3. 発進後の飛行AI（スウォーム旋回・攻撃ラン・爆撃）は現状のまま。

### R2. スパイダーキャリアは沖で待機する
- R2-1. 出現位置は海の**沖合**（海岸線から十分離れた水上）。
- R2-2. **脚を伸ばして直立**し、胴体が水面より上に出る姿勢をとる（海底 -20〜-47m ／ 脚の最大リーチ `L1+L2=126`）。
- R2-3. 待機中は**移動しない**（徘徊AI・脚ステップ・建物なぎ倒しを停止）。
- R2-4. 武装（主砲・誘導ミサイル・腹部砲門）は維持し、沖まで来たプレイヤーには反撃する。

### R3. 母艦から戦闘機・ウォーカーが発進する
- R3-1. 戦闘機は R1-2 のとおり母艦から発進。
- R3-2. ウォーカーは**母艦の真下に降り、海底を歩いて海岸へ上陸**する。上陸後は既存の徘徊・破壊AIに合流。
- R3-3. 「母艦出現中はウォーカーを出さない」という現行の排他ルール（`enemyAllowed()`）は、母艦がウォーカーの供給源になるため撤廃する。

### R4. シナリオ分岐で母艦が上陸・進攻する
- R4-1. 既存のイベント分岐（`badRoute` 系）をトリガに、母艦の待機モードを解除する。
- R4-2. 解除後は海岸へ向かって歩き出し、上陸後は**現状どおり**街を徘徊・蹂躙する（既存AIをそのまま使う）。

## 非機能要件

- N1. 母艦は遠景に常駐するため、画面外の脚IKスキップ（`sphereOnScreen`）を維持し、描画負荷を増やさない。
- N2. 海の位置・沖合距離はマップデータから算出し、座標をハードコードしない。
- N3. EP0（チュートリアル）は別系統のため影響なし。EP1（floz）は同じ仕組みで海側から侵攻する形になる。

## 要確認: 既存フローとの衝突点

### C1. 母艦を最初から出すと bad ED が即座に踏めてしまう
現行 `ep1_events.json` は `spiderDown`（母艦撃破）→ **bad ED** 直行。母艦が開始時から沖に居ると、プレイヤーが最初に沖へ飛んで倒すだけでEDになる。

| 案 | 内容 |
| --- | --- |
| **A（推奨）** | 分岐前の母艦は撃破不能（被弾は弾かれる演出）。R4の進攻開始で初めて撃破可能になり、そこから先は現行どおり bad ED。 |
| B | 分岐前に撃破できたら「増援を断った」＝**good 側の勝利ルート**として別ポートを用意する。 |
| C | 母艦は分岐まで出さず、戦闘機は「海の方角から飛来」だけにする（R3のウォーカー発進は分岐後のみ）。 |

### C2. 分岐前のウォーカー供給
現行はウォーカーも `attr50` イベントで初めて解禁される。母艦からの発進（R3-2）を**解禁前から**行うか、現行どおり `attr50` 以降に限るか。
→ 推奨: 現行どおり `spawnAllow.walker` を尊重し、解禁後の湧き方だけを「母艦から上陸」に変える（テンポを崩さない）。
