Web3D GameMaker

エディタ・ゲーム一覧（開発用ランチャー）— カードはドラッグで並び替え（この端末に保存されます）

ゲーム

TPS Flight GAME
サイキッカー(Joy_reborn)をTPS視点で操作する空中アクション。球面カメラ＋スプリング追従。浮遊物を目前に引き寄せ・射出。
AR Vampire Night ARGAME
吸血鬼JOY_vampが壁の闇穴/天井から現れプレイヤーを襲う。近づかれるとキスで生気を奪われる（10秒でダウン）。十字架を掴んで顔にかざし撃退、一夜(5分)を耐え抜く。マント=CPU布・フットロック接地。
Vampire Dungeon GAME
夜の洋館からの脱出FPS。徘徊する吸血鬼JOY_vampに見つかると追跡→捕獲(キス/吸血)。職員NPCが銃で救助してくれるが彼らも獲物に。金色のゴールに到達すれば脱出成功。ステージ生成(別棟/渡り廊下)＋編集モード内蔵。
CityFly GAME
街を自由飛行して破壊・捕食・生活NPC。自作マップ(既定 mytown、?map=名前で切替)。
Swing Catch GAME
空中のオブジェクト/VRM NPC をキャッチ・振り回し・吹っ飛ばす。NPCはステート/表情/ラグドール。
FPS VRM NPC + Cloth GAME
FPS視点でマント付きVRM NPCと布シミュ。発射→ラグドール。
FPS + Cloth GAME
FPS移動＋GPU布シミュレーション。
Cloth Sim GAME
WebGPU 布物理シミュレーション（形状パラメータ・エクスポート）。
Story Player GAME
3Dキャラ(npc.json)がしゃべり・動く線形ストーリーを再生。
Flow Player GAME
ストーリー→戦闘→勝敗で分岐するゲームフローを連続再生。

エディタ

Character Editor EDITOR
VRM NPC のステート（通常/警戒/攻撃/ダウン/復帰）に表情・視線・行動を設定し .npc.json として書き出す。
Cloth Editor EDITOR
VRMにマント等の布を着せ、ピン/コライダー/手グリップを設定して書き出す。
AR NPC Cloth AREDITOR
マント付きVRM NPC(megu/lily/ayu/eri/Joy/ken)をWebXR(AR/VR)で表示。マントはCPU布シミュで揺れ、床に等身大で立つ。目の前のカートでNPC切替・素材(粗さ/光沢/透明/環境光)をライブ調整、手/コントローラで操作＆カート移動。
FX Editor EDITOR
地面＋壁の小部屋でNPCのtimeline(VRMA)を再生し、任意フレームにエフェクト(炎/煙/火花/竜巻/自作)を配置。発生位置をギズモで移動/回転、bloom、timeline.json に埋め込み保存。
FX Builder EDITOR
基本図形＋テクスチャ＋色/加算合成/UVスクロール/ねじれ/自転/脈動 のレイヤーを重ねて発光VFXのプリセットを作成。粒子レイヤーも混在可。public/fx に保存し FX Editor で使える。
Bite Editor EDITOR
プレイヤーVRM＋NPCを並べ、噛む側/噛まれる側のVRMAを同時再生。口アンカーと噛みつき点をギズモで合わせ、Snapで「どんな体勢でも同じ首に噛みつく」アラインを調整。bite.json に保存。
Model Editor EDITOR
public/models/ の GLB をサムネ一覧から選び、ゲームに登場させる飛行オブジェクトを選別する。
Stage Editor EDITOR
俯瞰ビューでモデルをマウス配置。位置・回転を調整して swing-catch のステージ置物として保存する。
Building Generator EDITOR
香港風ビルをプロシージャル生成（階数・窓・室外機など18パラメータをスライダー調整）。BuildingGeneratorThreeJS (MIT / achrefelouafi) のビルド版。ステージ利用は検証中。
Room Editor EDITOR
kenney家具キットで部屋（壁・床・ドア・窓＋家具）をプロシージャル生成。タイプ/サイズ/シードで生成し、ギズモで手動調整して .room.json に保存。
Entry Editor EDITOR
city-fly の建物モデルに玄関/窓/光点/窓発光のマーカーを打つ。面をクリックして設置し building-entries.json に保存→ゲームでEキー進入点・夜の光になる。
Anim Editor EDITOR
VRMアニメーション編集の単独エディタ。IK（腰ピン留め/頭/手足・逆曲がり防止）＋関節FK＋キーフレームタイムライン→ .vrma 保存/読込。
Tool Editor EDITOR
道具の「持ち方」エディタ。VRMに武器/道具を持たせ、持ち手の位置/向きと添え手（IK目標）をギズモで調整し .tool.json に保存→ゲームでNPCが携行。
Damage Editor EDITOR
ダメージ損耗エディタ。.npc.jsonを読み、服やマントを部位単位で選択して溶解エフェクト（先端から/散り穴）を設定。ダメージ%スライダで損耗を確認し .damage.json に保存→City-Flyの被弾で反映。
Furniture Anim Editor EDITOR
家具インタラクションのポーズ編集。アンカー（NPC位置/向き）＋IK（腰/頭/手足）で「座る・寝る」を作り .vrma 保存→生活アクションに割当。
Map Editor EDITOR
自作マップエディタ。ハイトマップ地形をブラシで盛り上げ/掘り下げ・標高/傾斜の自動配色＋ペイントし .map.json に保存→ city-fly/?map=名前 で遊べる。
Ragdoll Editor EDITOR
NPCを崩して関節の回転制限を調整。グラブ点固定・関節/骨の可視化・即シミュ。ragdoll.json として保存。
Story Editor EDITOR
3Dストーリーのコマンド列を編集。アクター(npc.json)のセリフ・移動・モーション・カメラを設定し再生確認・保存。
Flow Editor EDITOR
ストーリー/戦闘ノードを接続し、勝敗で分岐するゲームフローを編集・保存。
VRM / MMD / FBX Editor EDITOR
モデル読込・アニメ再生・リターゲット・FBX→VRMA 変換などの本体エディタ。
各リンクは開発サーバーの相対パス（本番デプロイでは個別配置）。並び順をリセット
